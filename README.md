TIC-TAC-TOE
A command -line Tic Tac Toe game written in Python with ANSI -Styled terminal output
Requirment
Python 3.x
A terminal that supports ANSI escape code
How to play
1.check the board co ordinates( a1,a2,a3 for the top row, b1,b2,b3 for middle row, c1,c2,c3 for the bottom row)
2.Enter a position(such as b2 for center square
3.Players take turns placing their mark until someone gets three in a row, column ,diagonal or board is full.
